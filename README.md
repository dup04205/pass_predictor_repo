# 2027 국가직 9급 합격권 분석

직렬을 선택하고 과목별 점수를 입력하면 2027년 예측 커트라인 대비 합격 확률을 계산하는 정적 웹 페이지입니다.

## 구조

```
index.html      # 마크업
css/style.css   # 스타일
js/data.js      # 직렬별 예측 커트라인 데이터
js/main.js      # 계산 로직 및 렌더링
```

## 실행 방법

`index.html`을 브라우저로 열면 바로 동작합니다. 별도 빌드나 서버가 필요 없습니다. 

## 데이터 수정

직렬 추가/변경/커트라인 수정은 `js/data.js`만 편집하면 됩니다.
